# Signate_練習問題「お弁当の需要予測」
Signateの練習問題「お弁当の需要予測」について、需要数の予測モデル(重回帰モデル)を構築しました。
評価指標はRMSEで、提出したスコアは 10 でした。
順位は 472位 / 9,554人中（上位約5%、2026年1月時点）です。

## プロジェクト概要
- タスク: 日付・曜日・天気・メニュー情報などから、お弁当の需要数を予測する回帰問題
- モデル: scikit-learn を用いた重回帰モデル
- データ処理:
  - 分布・欠損の確認
  - カテゴリ変数（曜日・天気など）のダミー変数化
  - kcal・気温・降水量など数値特徴量を Box-Cox 変換してから標準化
  - 新規特徴量の作成（`year` / `month` / `day`、`is_otanoshi`、`is_curry`）
- 評価: 時系列の 5 分割（`TimeSeriesSplit(n_splits=5)`）による RMSE の算出

### 検証を時系列で分けた理由

売上の予測は、過去から未来を当てる問題である。
データを無作為に分けると、未来の日が訓練側に入り、手元の成績だけが良く出る。
そこで `TimeSeriesSplit` を使い、**訓練側が常に検証側より前の日付になるように分けた**。
`train_test_split` と `shuffle` はどちらも使っていない。

分割ごとの RMSE は次のとおりである。

| 分割 | 訓練の件数 | 検証の件数 | RMSE |
|---|---|---|---|
| 0 | 37 | 34 | 18.165 |
| 1 | 71 | 34 | 20.722 |
| 2 | 105 | 34 | 21.236 |
| 3 | 139 | 34 | 13.900 |
| 4 | 173 | 34 | 14.198 |

5 分割の平均は 17.644 である。訓練に使える日が増える後半の 2 分割で、誤差が小さくなっている。

## 全体方針      
1.訓練データの概要をつかむ。
2.各特徴量に4つの尺度(名義、順序、間隔、比例)を当てる。
3.特徴量エンジニアリング⓵:特徴量改善を行う。
4.特徴量エンジニアリング⓶:特徴量作成を行う。
5.特徴量エンジニアリング⓷:特徴量選択を行う。
6.訓練を通じ、特徴量エンジニアリングとモデル選択が正しいかを評価する。
7.テストデータの特徴量に同じ処理を施し、予測する。
8.予測結果をcsvへ出力する。
